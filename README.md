
# Epidemiology Trends in Interactive Charts

## 📊 Project Overview

Epidemiology Trends in Interactive Charts is an interactive data visualization project developed using Python, Streamlit, Pandas and Plotly.

The project helps users explore disease trends through interactive filters and charts.

## 🎯 Objectives

- Analyze disease cases across different years.
- Compare disease trends between regions.
- Analyze cases based on gender and age groups.
- Display total cases and deaths.
- Provide interactive charts for easy understanding of epidemiological data.

## 🦠 Diseases Covered

- Dengue
- Malaria
- Typhoid

## 🔎 Interactive Filters

Users can filter the dashboard based on:

- Disease
- Year
- Gender
- Region

## 📊 Visualizations

The dashboard provides:

- Total Cases
- Total Deaths
- Disease Cases Trend
- Disease Deaths Comparison
- Cases by Age Group
- Cases by Gender
- Cases by Region

## ▶️ How to Run

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run frontend/app.py
```

The application will open in the browser.
